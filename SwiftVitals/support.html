SwiftVitals Support

SwiftVitals is a local macOS tool for measuring the health of Swift codebases. If you need help, contact us at:

ryan.developer.ios@icloud.com

What to include in your message

Please include your macOS and Xcode versions, what you expected to happen, and the steps needed to reproduce the issue. Please do not attach private source code.

Coverage import

Coverage import requires Xcode. Select an existing .xcresult bundle, or grant read-only access to a Derived Data folder so SwiftVitals can find recent results.
